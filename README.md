## 🚀 המדריך הראשון: מבנה פרויקטים (Project Structure)

המדריך הראשון של "המפתח העברי" כבר באוויר! אחד הוויכוחים העתיקים והחשובים ביותר בכל צוות הנדסה הוא איך לנהל את קוד המקור שלנו.

במדריך זה אנחנו צוללים לעומק של:
* **Monorepo לעומת Multi-Repo:** מה זה בכלל אומר ברמת ה-Day-to-Day?
* **ההשפעה על הקוד:** איך המבנה משפיע על Dependency Management, קצב ה-CI/CD, ושותפות בקוד (Code Sharing).
* **מתי לבחור במה?** מטריצת החלטה מבוססת ניסיון מהשטח.

👉 **[לקריאת המדריך המלא על Project Structure לחצו כאן](./software-engineering/project-structure.md)**
